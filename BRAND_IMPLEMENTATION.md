# Wildpath Brand Implementation

The supplied brand board and logo files are implemented directly in the website.

## Logos
- `public/brand/wildpath-logo-light.png` — supplied first image; used in the navigation and footer.
- `public/brand/wildpath-logo-dark.png` — used on light content areas where the dark artwork has sufficient contrast.
- `public/brand/wildpath-logo-stacked-dark.png` — used as an editorial brand mark on the homepage.

## Colours
The CSS variables in `app/globals.css` use the supplied palette exactly:
- `#260E09`
- `#7B3013`
- `#FDFBF8`
- `#FFD699`
- `#DF6E0E`
- `#F9BD33`
- `#454411`

## Typography
The brand board references Bauer Bodoni Condensed, TT Hoves and Virtual. The CSS stacks reference those family names first but no proprietary font files are bundled. Licensed webfont files can be connected later if supplied by the client.
